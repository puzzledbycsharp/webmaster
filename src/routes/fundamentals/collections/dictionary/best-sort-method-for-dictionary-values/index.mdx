## Introduction

While a dictionary by it's nature is not sorted and doesn't hold a order. It are times when it is neccessary to sort the dictionary by the value. Usually these are just one time operations where we wouldn't need to convert the dictionary to a list to save the order. Also, the goal is here not convert the dictionary to a different collection type like a list. The reason why you wouldn't want to be convert between collection types is that it would be costly in performance.

The way to iterate through a dictionary is to use the Dictionary Keys and Dictionary Values methods. They have the best performance but they they only give Keys or Values. If you want to have access to both Keys and Values at the same time then it would be best to use a list to package them tegether in a class. But if you're restricted to only a dictionary then Dictionary's Key-Value Pair method is good enough too. Next is the deconstructor of dictionary, I think this can be avoided because it is slower than the Key-Value Pair method that is natively supported in dictionary. The readablity gains from this is not worth the loss in performance. The last method on the list is extremely slow and should be avoided and that is the Dictionary Keys Then Dictionary Access method. It suffers as the dictionary grows in size. This does not scale.
