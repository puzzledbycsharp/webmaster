## Introduction

System Array is an abstract class that can only instantiated through a function. From the class name itself it's hard to tell if the what type it encapsulate so you'll need plan and be sure what time it is ahead of time. [Since System Array is not in the collection namespace but it is still considered a collection since it implements IList](https://learn.microsoft.com/en-us/dotnet/api/system.array?view=net-7.0) There are other types of arrays in the collection name space so I will be refereing this array as system array to advoid confusion. With this we can convert System Array to a List so I'll go over the methods one by one and provide analysis of each one.

#### What Methods Converts a System Array into a List?

There are a few ways to do this and all of them involve a cast of some sort. One is to write our own method to loop the system array and add them to a list. The second uses a array cast then using ToList. Lastly the other method is to use OfType to cast the objects then use ToList to assign it to a list. All of these methods can get the result that we want but the difference in performance will be key to determine which is the best to use.

### Loop Method
<ImageWrapper imageSource="../../../../assets/fundamentals/collections/list/convert-a-system-array-to-a-list/loop-method-section-image.webp" altImage = "Loop Method Section Image" widthImage = "1400" heightImage = "300" />

First method to convert all the System Array items to a list is through the brute force method of looping through all the items. Then applying a cast to each item retrieved and then adding it to the list. Examine the below code.

```cs
Array systemArray = Array.CreateInstance(typeof(int), 4);//Create System Array with type int and length of 4
systemArray.SetValue(10, 0);//Set value to 10 at index 0
systemArray.SetValue(21, 1);//Set value to 21 at index 1
systemArray.SetValue(32, 2);//Set value to 32 at index 2
systemArray.SetValue(43, 3);//Set value to 43 at index 3
List<int> list = new List<int>();
for (int i = systemArray.GetLowerBound(0); i <= systemArray.GetUpperBound(0); i++)
{
    list.Add((int)systemArray.GetValue(i));//Get value from System Array then cast it to int then add it to the list.
}

Console.WriteLine("list:" + string.Join(",", list));//Print to screen

```

### Cast and ToList Method

<ImageWrapper imageSource="../../../../assets/fundamentals/collections/list/convert-a-system-array-to-a-list/cast-and-tolist-section.webp" altImage = "Cast and ToList Method Section Image" widthImage = "1400" heightImage = "300" />

Another way to we can solve this issue is to cast The System Array object to an array. Then convert that array to a list.

```cs

systemArray.SetValue(21, 1);//Set value to 21 at index 1
systemArray.SetValue(32, 2);//Set value to 32 at index 2
systemArray.SetValue(43, 3);//Set value to 43 at index 3
List<int> myList = ((int[])systemArray).ToList();
Console.WriteLine("myList:" + String.Join(",", myList));//Print to screen
```

###### Code Output


This gives us the same output as before so this cast to array succeeds. Let's check out the performance of this method.

### OfType and ToList Method

<ImageWrapper imageSource="../../../../assets/fundamentals/collections/list/convert-a-system-array-to-a-list/oftype-tolist-section.webp" altImage = "OfType and ToList Method Section Image" widthImage = "1400" heightImage = "300" />

Lastly, we'll look at the OfType Method. [This method filters out objects that can be cast the type and returns a IEnumerable.](https://learn.microsoft.com/en-us/dotnet/api/system.linq.enumerable.oftype?view=net-7.0) We can use this method to convert a System Array to a IEnumerable then to a list. 

```cs
Array systemArray = Array.CreateInstance(typeof(int), 4);//Create System Array with type int and length of 4
systemArray.SetValue(10, 0);//Set value to 10 at index 0
systemArray.SetValue(21, 1);//Set value to 21 at index 1
systemArray.SetValue(32, 2);//Set value to 32 at index 2
systemArray.SetValue(43, 3);//Set value to 43 at index 3
List<int> myList = systemArray.OfType<int>().ToList();//Filter out all objects that can be cast to int then change IEnumerable type to List with ToList
Console.WriteLine("myList:" + String.Join(",", myList));//Print to screen=
```
###### Code Output

```
myList:10,21,32,43
```

As expected this produces the expected result. Now lets take a look at the speed of this method.

### Conclusion
<Table header ="Overall Rank,Method,Speed" rows="1,Cast and ToList,109ms;2,Loop,3532ms;3,OfType and ToList,3736ms;" />

The best method for converting a system array to a list is to cast it to array of that type then use ToList. It has really good performance that is far better than the other two methods. This call all be done on one line so it's compact and readability. Looping through the array and adding to a list is almost as slow as using OfType that it isn't worth it write unless you need to. Even though the typeOf and ToList can fit one line of code, it is too slow and shouldn't be used compared to the other methods.
