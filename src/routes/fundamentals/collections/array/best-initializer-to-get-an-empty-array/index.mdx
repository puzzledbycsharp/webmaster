## Introduction

The goal here is to create a non null array with size 0. C# can create an empty array through the array initializer and static array method. So it can depend on your preference on which you want to use. There are various reasons why you might want to do this. You may not know up front the size of the array so you want a place holder for when you will know the size. You may want to return a empty array from a function if there's a failure or invalid input. Whatever the reason, empty array have a place in code but beware that they are there in the code an offer sufficient checks on the array to to insure that you don't try to access elements in an empty array so that an exception isn't thrown. 

All arrays must provide a size wheither it is explicit or implict so empty array is size 0. Let's look at some examples.

### Empty Array With The Array Initializer

This works by pass not values into the brackets [] and nothing in the curly braces {}. This works for all the different types found in C# and even classes that you create.

#### Empty Array With The Array Initializer Code Example

This code uses the the array initializer syntax to provide an empty array by keeping the brackets and curly braces empty. The array created will have a length of zero but not null. 

```cs
string[] stringArray = new string[] { };//Allocates an string array of size 0
Car[] classArray = new Car[] { };//Allocates an car array of size 0
double[] doubleArray = new double[] { };//Allocates an double array of size 0
int[] intArray = new int[] { };//Allocates an int array of size 0
float[] floatArray = new float[] { };//Allocates an float array of size 0
bool[] boolArray = new bool[] { };//Allocates an bool array of size 0

PrintArray<string>(stringArray, "stringArray");
PrintArray<Car>(classArray, "classArray");
PrintArray<double>(doubleArray, "doubleArray");
PrintArray<int>(intArray, "intArray");
PrintArray<float>(floatArray, "floatArray");
PrintArray<bool>(boolArray, "boolArray");

void PrintArray<T>(T[] array, string ArrayName)
{
    if(array.Length == 0)
    {
        Console.WriteLine($"{ArrayName}:Length == 0");
    }
}

class Car
{
    public int WheelCount { get; set; }
    public int TopSpeed { get; set; }
    public string Type { get; set; }
}
```

###### Code Output
```
stringArray:Length == 0
classArray:Length == 0
doubleArray:Length == 0
intArray:Length == 0
floatArray:Length == 0
boolArray:Length == 0
```

This is a non null array but with a size of 0 just like we want.

### Empty Array With Static Array Empty Method

Array has a static method to return a empty array for us. [This was avialable in .NET 4.6](https://learn.microsoft.com/en-us/dotnet/api/system.array.empty?view=net-7.0) It is one of the standard ways provided in csharp. It is clearly says empty so it is readable and easy to use. Below are is an example

#### Empty Array With Static Array Empty Method Example Code


```cs
string[] stringArray = Array.Empty<string>();//Returns an string array of size 0
Car[] classArray = Array.Empty<Car>();//Returns an car array of size 0
double[] doubleArray = Array.Empty<double>();//Returns an double array of size 0
int[] intArray = Array.Empty<int>();//Returns an int array of size 0
float[] floatArray = Array.Empty<float>();//Returns an float array of size 0
bool[] boolArray = Array.Empty<bool>();//Returns an bool array of size 0
```

###### Code Output

```
stringArray:Length == 0
classArray:Length == 0
doubleArray:Length == 0
intArray:Length == 0
floatArray:Length == 0
boolArray:Length == 0
```


### Empty Array With LINQ Enumerable Empty

LINQ provide another method which is a two step process. It creates an empty IEnumerable object then coverts it into an array via LINQ. [It is useful when working with LINQ expressions and examples like UNION.](https://learn.microsoft.com/en-us/dotnet/api/system.linq.enumerable.empty?view=net-7.0#remarks) Let's see an example. 

#### Empty Array With LINQ Enumerable Empty Example Code

LINQ Enumerable Empty requires a type to return for each type. This is comparable to Array's empty method but here there more code to write with the ToArray.

```cs
string[] stringArray = Enumerable.Empty<string>().ToArray();//Returns an string array of size 0
Car[] classArray = Enumerable.Empty<Car>().ToArray();//Returns an car array of size 0
double[] doubleArray = Enumerable.Empty<double>().ToArray();//Returns an double array of size 0
int[] intArray = Enumerable.Empty<int>().ToArray();//Returns an int array of size 0
float[] floatArray = Enumerable.Empty<float>().ToArray();//Returns an float array of size 0
bool[] boolArray = Enumerable.Empty<bool>().ToArray();//Returns an bool array of size 0
```

###### Code Output

```
stringArray:Length == 0
classArray:Length == 0
doubleArray:Length == 0
intArray:Length == 0
floatArray:Length == 0
boolArray:Length == 0
```


### Empty Array With LINQ Enumerable Repeat

Enumerable Repeat allows us to create a repeating pattern of zero and so it will return an empty array. [It has two parameters, the value to be repeated and the number repetitions.](https://learn.microsoft.com/en-us/dotnet/api/system.linq.enumerable.repeat?view=net-7.0#examples) But it is tedious to provide different values to repeat even though they will not be repeated. This method was not made to create empty arrays even though it can do so.

#### Empty Array With LINQ Enumerable Repeat Example Code

For each type, you need to pass a dummy value which is unnecessary.

```cs
string[] stringArray = Enumerable.Repeat("", 0).ToArray();//Returns an string array of size 0
Car[] classArray = Enumerable.Repeat(new Car(), 0).ToArray();//Returns an car array of size 0
double[] doubleArray = Enumerable.Repeat(0.0, 0).ToArray();//Returns an double array of size 0
int[] intArray = Enumerable.Repeat(0, 0).ToArray();//Returns an int array of size 0
float[] floatArray = Enumerable.Repeat(0f, 0).ToArray();//Returns an float array of size 0
bool[] boolArray = Enumerable.Repeat(false, 0).ToArray();//Returns an bool array of size 0
```

###### Code Output

```
stringArray:Length == 0
classArray:Length == 0
doubleArray:Length == 0
intArray:Length == 0
floatArray:Length == 0
boolArray:Length == 0
```

### Conclusion

The best method for initializing a empty array is the static array empty method. It is short and readable. It says what it does and you don't want confuse people with syntax if they are new. It works on a return method and in declaration for global methods.

Array Initializer are the next best because they are available across the different csharp version but they vary greatly so you'll have to pick which one works for you. The shorthand version is extremely short but might be hard to read as it doesn't describle anything which is bad coding practice.

Enumerable Empty is readiable but it is a two step process and since the static array empty method is there is no need to use. this

Enumerable Repeat is a tedious as I said before and shouldn't be used and it wasn't made to create empty arrays in mind but to repeat other patterns at scale.  

Creating a new list then converting it to an array. Again, it's a two step process and is not needed when there are only one step methods to create an empty array.
