## Introduction

You may want to do a partial copy of an array to another for various reasons. It could be copying the entire array is more expensive or just too big if you are working with a lot of data. It can be more memory efficitent. 

This is more important in low memory use cases such as embeded systems. Or You may face memory limitations in 32-bit applications. In today's appliations memory ussage usually isn't a problem with 64 bit having access to large amounts of memory. But you still don't want to be wasteful of that resource because there may   

In general it is good programming practice to only do what is needed. The other advantage is that it is faster to only copy part of an array rather than the whole array. If you have an array of a million objects and you only need copy a few thousand then this copy operation would over time be more effeccient. This of course works best when you can copy chunks of data at a time. Since an array is a continous block of memory have a range of data is best and so make sure to originaze your data as such so that a block of data can be copied at a time.

Also another area that copying only part of the array could lead to more efficient code. Let me explain. If you have a subsection of data in an array. It could lead to less compilcated code if you have an array that decicated to the task.
